# Guía de Onboarding — Nuevos Empleados

## Antes del Primer Día

Antes de tu ingreso, RRHH enviará a tu correo personal:
- Contrato de trabajo para firma digital.
- Formulario de datos personales y bancarios.
- Enlace para configurar tu cuenta corporativa (correo y VPN).
- Lista de documentos a traer el primer día (cédula, certificados, etc.).

## Primer Día

### Llegada
- Presentarte en recepción con tu cédula de identidad.
- El área de RRHH te recibirá a las **09:00** para completar el proceso de ingreso.
- Duración aproximada: 2 horas.

### Documentos a Entregar
- Cédula de identidad (original + copia).
- Certificado de antecedentes (vigente últimos 90 días).
- Cartola bancaria o comprobante de cuenta para depósito de sueldo.
- Certificado de título o estudios (según posición).

### Materiales que Recibirás
- Credencial de acceso a las instalaciones.
- Laptop corporativo configurado con tu cuenta.
- Kit de bienvenida con artículos de la empresa.

## Primera Semana

| Día | Actividad |
|-----|-----------|
| Lunes | Inducción con RRHH — Políticas, beneficios, código de conducta |
| Martes | Reunión de bienvenida con tu equipo y jefatura directa |
| Miércoles | Configuración de herramientas (correo, Slack, sistemas internos) |
| Jueves | Tour por las instalaciones + accesos a sistemas de tu área |
| Viernes | Check-in con RRHH para resolver dudas |

## Accesos y Sistemas

Para gestionar tus accesos, envía un ticket a helpdesk@empresa.com con:
- Nombre completo
- Área y cargo
- Sistemas requeridos (indicar cuáles)

Tiempo de respuesta: **24-48 horas hábiles**.

Sistemas corporativos principales:
- **Correo**: Google Workspace (Gmail)
- **Comunicación**: Slack
- **Gestión de proyectos**: Jira
- **RRHH**: Portal HR (hr.empresa.internal)
- **Documentos**: Google Drive corporativo

## Período de Prueba

Los primeros **90 días** corresponden al período de prueba. Durante este período:
- Tendrás reuniones quincenales de seguimiento con tu jefatura.
- RRHH realizará una evaluación de adaptación al mes 1 y al mes 3.
- Cualquier consulta puede dirigirse a rrhh@empresa.com.
